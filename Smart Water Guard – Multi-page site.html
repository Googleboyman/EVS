A smart plumbing idea that closes the valve when water runs where it should not.

Point 1 of 5

Problem and idea

The problem

In the NSSKC Plumbing Lab, water is supplied, used and drained through pipes, joints and taps. A slow leak or a tap left running can go unnoticed, and the water is lost.

Our idea

Place a flow sensor on the supply line, connected to a small microcontroller. If water flows when nobody is using a fixture, or a tap runs for too long, the controller sounds an alarm and closes a solenoid valve.

How it could help

The aim is to stop a leak sooner than a person would notice it, and to keep a log of when it happened. The figures on the simulation page are made up for demonstration. We have not measured real savings.

Sustainable Development Goals

  • SDG 6, Clean Water and Sanitation: reduces wasted water.
  • SDG 11, Sustainable Cities and Communities: a low-cost idea that could be adapted for buildings.

Point 3 of 5

Control logic and code

  1. Read the flow sensor once a minute.
  2. Check whether a fixture is meant to be in use.
  3. If water flows with no fixture in use for 5 minutes, or a tap runs for 15 minutes, raise the alarm.
  4. Close the valve and record the event.
  5. Wait for a person to repair the problem and press reset.

The 5 and 15 minute limits are example settings that a real installation would need to tune.

Concept Arduino sketch

// Concept only, not tested on hardware
const int FLOW=2, VALVE=7, BUZ=8;
volatile int pulses=0; int bad=0, tapOn=0;
void setup(){
  pinMode(VALVE,OUTPUT); pinMode(BUZ,OUTPUT);
  digitalWrite(VALVE,HIGH);                 // valve open
  attachInterrupt(digitalPinToInterrupt(FLOW),[]{pulses++;},RISING);
}
void loop(){
  delay(60000);                             // one minute
  float lpm = pulses/7.5; pulses=0;         // typical for YF-S201
  bool inUse = tapInUse();                  // button or schedule input
  if(lpm>0 && !inUse) bad++; else bad=0;
  tapOn = (inUse && lpm>0) ? tapOn+1 : 0;
  if(bad>=5 || tapOn>=15){
    digitalWrite(BUZ,HIGH);
    digitalWrite(VALVE,LOW);                // close valve
  }
}
